# AIM CARTE（エイムカルテ）

プレイを分析して弱点を診断し、次に意識することと練習を「処方」する FPS エイム練習ソフトです。
インストール不要で、ブラウザだけで遊べます。

**▶ 今すぐ遊ぶ: https://cover1sea.github.io/aim-carte/**

## 動作環境

- PC のブラウザ（Chrome / Edge 推奨）とマウス
- 全画面でのプレイがおすすめです（F11 キー。Mac は ⌘ + Ctrl + F）

## はじめ方

1. **感度・設定** で、普段遊んでいるゲーム（Overwatch 2 / VALORANT / Apex Legends / カスタム）の感度・DPI・FOV を入力します。振り向き量と視野がゲームと同じになります。
2. **総合ベンチマーク**（約 4 分）で、6 つの要素を 30 秒ずつ計測します。スキルレーダーと、全体を通した弱点が分かります。
3. 結果画面のフィードバックを読み、**トレーニングメニュー** か **おすすめ練習** で弱点を練習します。
4. ときどきベンチマークを測り直して、**履歴** で伸びを確かめます。

## 操作

| 操作 | キー・マウス |
|---|---|
| 撃つ | 左クリック（トラッキング系は長押し） |
| 移動（移動シナリオのみ） | W / A / S / D |
| 一時停止（再開・リトライ・中断） | ESC |
| 全画面 | F11（Mac は ⌘ + Ctrl + F） |

## 主な機能

- **シナリオ**: エイムの要素ごとの練習と、それらを組み合わせた総合練習
- **トレーニングメニュー**: ウォームアップ → 集中練習 → ミックス → 確認 の順に組んだメニュー。各ステップの前に「意識すること」と目標を表示
- **上級者比とランク**: 各シナリオの「上級者の目安」を 100% とした成績と 7 段階のランク。目安は共通の前提値から計算し、計算式も表示
- **プレイ後のフィードバック**: 一振り目の精度、行き過ぎ・手前止まり、マウスの傾き、トラッキングの遅れ (ms)、切り返しへの反応の内訳などを分析し、強み・弱点・次に意識することを根拠つきで提示
- **練習シナリオの生成**: 弱点と今の実力に合わせて練習用シナリオを作成
- **記録**: 履歴グラフ、練習カレンダー、自己ベスト、リプレイ（照準の軌跡つき）

## 記録の保存について

プレイ記録と設定は、使っているブラウザの中にだけ保存されます。サーバーには送信しません。
別のブラウザや別の PC には引き継がれず、ブラウザのデータを消すと記録も消えます。

## 分析の根拠

フィードバックは、運動制御・ヒューマンインタフェースの研究と、競技エイムコミュニティ（Voltaic、Aim Labs など）の資料をもとにしています。
出典で確かめられなかった助言は、アプリ内で「本アプリの経験則」と明記しています。
詳しい説明と参考文献は、アプリの **理論** ページにまとめています。

## 開発

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # dist/ に出力
```

| ファイル | 内容 |
|---|---|
| `src/settings.js` | 感度・FOV の換算 |
| `src/scenarios.js` | シナリオ定義 |
| `src/engine.js` | 描画・入力・移動・記録・リプレイ |
| `src/analysis.js` | 指標の計算・スコア・上級者比 |
| `src/reference.js` | 上級者の目安の計算 |
| `src/feedback.js` | 診断・参考文献・シナリオ生成 |
| `src/training.js` | トレーニングメニュー |
| `src/main.js` | 画面 |
| `public/sfx/` | 効果音 |
